# Evolet HRM

Учёт сотрудников и техники: карточки людей, структура компании, оборудование с журналом операций и доступы по позициям. Laravel 12, Inertia и React, интерфейс на русском.

## Запуск в браузере (GitHub Codespaces)

Годится, когда под рукой нет машины с PHP — например, с планшета.

1. На странице репозитория: **Code** → вкладка **Codespaces** → **Create codespace on main**.
2. Подождать 3–5 минут. Окружение соберётся само: зависимости, `.env`, база SQLite с демо-данными, сборка фронтенда.
3. В терминале запустить всё разом:
   ```bash
   composer run dev
   ```
4. Открыть вкладку **Ports** и перейти по адресу порта **8000**.
5. Войти: `admin@evolet.test` / `password`.

Живая перезагрузка (Vite) работает, если в той же вкладке **Ports** у порта **5173** выставить видимость **Public** — иначе браузер не сможет открыть сокет обновлений, и страницу нужно будет перезагружать руками. Без этого приложение работает на собранных файлах: после правок фронтенда достаточно `npm run build`.

## Запуск на своей машине

Нужны PHP 8.4+, Composer, Node 22+ и MySQL (подойдёт Laragon, Herd, XAMPP).

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
# создать базу hrm и прописать её в .env
php artisan migrate --seed
composer run dev
```

Если MySQL поднимать не хочется, работает тот же путь, что и в Codespaces: в `.env` поставить `DB_CONNECTION=sqlite`, а в `DB_DATABASE` — полный путь к файлу `database/database.sqlite`.

## Демо-данные

Сидер создаёт системного администратора, 67 работающих сотрудников с должностями, отделами и языками, а также технику по категориям с журналом передач. Пароль у всех — `password`.

| Кто | Вход |
| --- | --- |
| Системный администратор | `admin@evolet.test` |
| Обычный сотрудник | любой из списка сотрудников, например `f.rakhimov@evolet.test` |

Пересобрать данные с нуля:

```bash
php artisan migrate:fresh --seed
```

## Как устроен доступ

Права описаны в `app/Support/Access.php` — раздел плюс действие («Сотрудники: личные данные», «Оборудование: журнал операций»). Набор прав висит на позиции, а отдельному сотруднику право можно выдать или снять персонально; персональное решение сильнее позиции и применяется в `User::hasPermissionTo()`.

Кто кому выдаёт доступы, решает роль «Системный администратор»: администратор проходит любую проверку, но не может назначить другого администратора или снять с него права. Таблица «позиции × права» — в разделе **Справочники → Доступы**.

## Что ещё стоит знать

- Схема хранится в исходных `create`-миграциях: пока проект не в продакшене, изменения вносятся в них, а не отдельными `add`-миграциями.
- Поля единиц техники задаются у категории («Мониторы» — диагональ, «Телефоны» — IMEI), поэтому у карточки монитора нет пустого «Процессора».
- Кнопка «Сфотографировать» требует защищённого соединения: работает на `localhost` и по HTTPS, но не по обычному `http://` с внешнего адреса.
